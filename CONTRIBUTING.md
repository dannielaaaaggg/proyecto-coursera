# Guía de Contribución

¡Gracias por considerar contribuir a este proyecto!

## Cómo contribuir

1. **Fork** este repositorio.
2. Crea una nueva rama con un nombre descriptivo:
3. Realiza tus cambios y confírmalos:
4. Sube los cambios a tu fork:
5. Abre un **Pull Request** en este repositorio original.

## Requisitos

- Sigue las buenas prácticas de programación.
- Escribe mensajes de commit claros y descriptivos.
- Si tu contribución cambia la funcionalidad existente, actualiza la documentación.

## Código de Conducta

Por favor, revisa el [Código de Conducta](CODE_OF_CONDUCT.md) antes de contribuir.
